# Moda İskelesi Vapur Kafe

Kadıköy'deki Moda İskelesi Vapur Kafe için tek sayfalık tanıtım sitesi.

- Tek dosya: `index.html` (CSS ve JS içinde, dışarıdan kütüphane yok)
- Türkçe, telefonda da çalışır
- İletişim formu şimdilik yalnızca görünüm, mesaj göndermez

## Çalıştırma

Proje klasöründe:

```
python -m http.server 3000
```

Sonra tarayıcıda `http://localhost:3000/index.html` adresini aç.
